How to put a password on a ZIP file in Windows 11

Updated 11 November 2026 · Windows 10 and 11

Windows can make ZIP files (right-click › Compress to), but it can't add a password. Here's how to make a password ZIP that still opens on any PC or Mac, and a stronger way for sensitive files.

How to do it

  1. Get OrbitDrop from the Microsoft Store.
  2. Right-click the folder or file in File Explorer and choose Lock with OrbitDrop.
  3. Type a password. A password ZIP is saved next to it. Windows and a Mac ask for the password when it's opened.

How strong is it?

OrbitDrop uses standard ZIP encryption so the ZIP opens anywhere without extra apps. That's fine for keeping files away from casual eyes, but it's not the strongest. For sensitive files, use the way below.

Stronger: 7-Zip with AES-256

Install the free 7-Zip, right-click the files › 7-Zip › Add to archive, type a password and choose AES-256. Whoever opens it needs 7-Zip or a similar app, because Windows' built-in ZIP can't open AES files.

A PDF or Office file?

Lock keeps those as they are, with their own stronger password: a PDF stays a PDF, a Word file stays a Word file. Password-protect a PDF.

Questions

Can Windows open a password ZIP?

Yes, for standard ZIP encryption: File Explorer asks for the password when you open or extract a file inside.

Is it free?

Lock is part of the OrbitDrop upgrade ($4.99 once), free to try for a day. 7-Zip is free.
