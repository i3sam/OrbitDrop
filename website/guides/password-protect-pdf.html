How to put a password on a PDF on Windows

Updated 11 November 2026 · Windows 10 and 11

Windows can make PDFs, but it can't put a password on one, and uploading a bank statement or a contract to a website to do it isn't great. Here are two ways that work offline.

How to do it

  1. Get OrbitDrop from the Microsoft Store.
  2. Right-click the PDF in File Explorer and choose Lock with OrbitDrop.
  3. Type a password. The locked copy is saved next to it, still a .pdf, and opens in any PDF reader with the password.

From Word, when you save

If the document starts in Word: File › Save As, choose PDF, click Options and tick Encrypt the document with a password. That works for documents you make in Word, not for a PDF you already have.

Other files too

Lock works on any file: Word, Excel and PowerPoint keep Office's own password, and anything else becomes a password ZIP. More about Lock.

Questions

How strong is the password?

OrbitDrop locks PDFs with AES-256, the strongest standard PDF encryption.

What if I forget it?

There's no way back in, and OrbitDrop doesn't keep a copy. Keep the password somewhere safe.

Is it free?

Lock is part of the OrbitDrop upgrade ($4.99 once), free to try for a day. Word's option is free if you have Word.
