How to convert WebP to JPG on Windows

Updated 5 November 2026 · Windows 10 and 11

Saved a picture from a website and got a .webp file that won't upload or open where you need it? Here's how to make it a JPG in a couple of seconds.

How to do it

  1. Get OrbitDrop, free on the Microsoft Store.
  2. Start dragging the file in File Explorer and, while you're still holding it, tap Shift. A wheel opens under your pointer. Let go on JPG.
  3. The new file appears next to the original, which is never changed. Made a mistake? Click Undo on the card that appears.

Many WebP files at once

Select all of them, start dragging, tap Shift and let go on JPG: every file is converted, side by side. Prefer not to drag? Select the file, press Ctrl + Alt + Space and click JPG.

Other formats

The same wheel turns WebP into PNG (keeps transparency), PDF, GIF, BMP or TIFF. It works the other way too: drag a JPG or PNG and let go on WebP for a much smaller file for your website.

Without installing anything

On Windows 11, right-click the WebP › Open with › Paint, then File › Save as › JPEG picture. It works, but one file at a time.

Questions

Does converting WebP to JPG lose quality?

Hardly. JPG is saved at high quality, so you won't see a difference. If the WebP has a transparent background, choose PNG instead: JPG can't be transparent.

Is it safe? Are my pictures uploaded?

Nothing is uploaded. OrbitDrop converts on your PC, offline, and keeps your original file.
